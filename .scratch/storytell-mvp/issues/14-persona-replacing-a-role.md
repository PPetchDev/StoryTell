# When a Persona replaces a Role

Type: grilling
Status: resolved
Blocked by: none
Part of: [Map: Storytell AI MVP](../map.md)

## Question

When can the user wear a Persona in place of a Story's Role, and how do Characters perceive a switch mid-Chat?

## Answer

- The user can switch between the Story's Role and any Persona at any time, including mid-Chat (unlike Zeta, which forbids mid-Chat switching).
- Characters treat a switch as the same person with changed details: Bond and Memory carry over unchanged; only the name and description the Characters see change. No per-Persona Bond is kept.
