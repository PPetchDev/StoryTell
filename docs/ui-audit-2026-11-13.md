# UI/UX audit รอบ 2 — apps/web (ตรวจจากหน้าจอจริง)

ตรวจเมื่อ 2026-11-13 ที่ commit `5fb8896` บน dev server (ข้อมูลจริง: Story "Welcome To Her Tribe", Chat 2 ยาว 167 Messages, 6 Characters, 17 Scenes) — **รายงานอย่างเดียว ยังไม่ได้แก้โค้ด**

รอบแรก ([ui-audit.md](ui-audit.md), 2026-11-12) ตรวจจากโค้ด รอบนี้ตรวจจาก**สิ่งที่ผู้ใช้เห็นจริง**: ถ่ายหน้าจอทุกหน้าที่ 390px ทั้งธีมมืดและสว่าง (43 ภาพ) + desktop 1280px, รัน axe-core (WCAG 2.2 AA) ทุกหน้า, วัดขนาดปุ่ม/ตัวอักษร/การล้นจอด้วยสคริปต์ และจับเวลา API

## สรุป

**High 2 · Medium 18 · Low 15** — ไม่มี Critical

ข่าวดี: ของที่รอบแรกเจอส่วนใหญ่แก้แล้วจริง และเครื่องมือวัดไม่เจออะไรเลย ปัญหาที่เหลือเป็นเรื่อง **ความเร็ว** กับ **ความยาว/ความรกของหน้า** มากกว่าเรื่อง accessibility

1. **ช้า** — หน้า Home รอ API 3.5–3.9 วินาทีทุกครั้ง หน้า Story/Chat/Memory รอ ~2 วินาที (H1)
2. **หน้า editor ยาวเกินไป** — แท็บ Characters ยาว 25,856px (~31 จอ) เพราะทุก card เปิดหมด (H2)
3. **หน้าแชตรก** — ไอคอนที่ไม่มีป้าย, แถว Character ถูกตัด, เมนูแชตยาวไม่จัดกลุ่ม (M2–M5)
4. **Settings/Usage จัดลำดับไม่ชัด** — ส่วนของ Owner ปนกับส่วนส่วนตัว, ตัวเลข Usage ถูกบีบ (M14–M15)

## High (2)

**H1. API ช้า: หน้า Home รอ 3.5–3.9 วินาทีทุกครั้ง**
- วัด: `GET /api/stories` 3.86s / 3.48s / 3.63s (ได้ข้อมูลแค่ 479 bytes) เทียบ `/api/health` 2ms; `/api/stories/1` 1.7s, `/api/stories/1/chats/2` 1.9s, `/memories` 2.1s, `/gallery` ~2s (หน้า Gallery ยังขึ้น "Loading the Gallery…" หลัง 10 วินาที)
- สาเหตุที่น่าจะเป็น: `StoryModelService.findAllFull`/`findFull` โหลดทุก relation (Characters → Expressions, Scenes → Bond gates, Lore, Starting bonds/beliefs…) ใน query เดียว TypeORM จึง JOIN แล้วได้แถวคูณกันหลายพัน (cartesian product) ทั้งที่ Home ต้องการแค่ชื่อ, cover และสถานะ
- แก้: ใช้ `relationLoadStrategy: 'query'` (แยก query ต่อ relation) ใน `apps/api/src/model/story/story.service.ts` และให้ `listStories` โหลดเฉพาะที่ใช้ — ควรวัดซ้ำบนเครื่อง Oracle ด้วย
- ไฟล์: `apps/api/src/model/story/story.service.ts`, `apps/api/src/manager/story/story.service.ts:228`
- **แก้แล้ว (2026-11-13):** ยืนยันสาเหตุ — Story 1 JOIN กันได้ ~25,700 แถว (Expressions 28 × Starting bonds 6 × Scenes 17 × Lore 9) และ query เดียว JOIN ถึง 10 ตาราง เปลี่ยนเป็น `relationLoadStrategy: 'query'` แล้ววัดบน dev (ค่ากลางของ 3 ครั้ง):

  | API | ก่อน | หลัง |
  |---|---|---|
  | `/api/stories` (Home) | 3.63s | 0.016s |
  | `/api/stories/1` | 1.7s | 0.015s |
  | `/api/stories/1/chats/2` | 1.9s | 0.08s |
  | `/api/stories/1/gallery` | ~2s | 0.015s |
  | `/api/stories/1/chats/2/memories` | 2.1s | 0.52s (ยังมีสาเหตุอื่น) |

  เทส `apps/api/test/story-loading.spec.ts` กันไม่ให้ query ไหน JOIN ตารางแบบหลายแถวเกินหนึ่งตารางอีก

**H2. แท็บ Characters ยาว 25,856px (~31 จอ), Scenes 21,995px, Lore 10,145px**
- หลักฐาน: `*-editor-characters.png`, `*-editor-scenes.png` — ทุก card เปิดหมดตั้งแต่แรก; Character หนึ่งคนมี Expression 7 ตัว ตัวละ 5 ปุ่มใน 3 แถว (~215px ต่อ Expression, ~1,500px ต่อ Character); Scene 17 อันซ้ำ hint ยาว 3 อันทุกอัน; ย้าย Scene 17 ขึ้นบนสุดต้องกด ↑ 16 ครั้ง
- แก้: เปิดเฉพาะ card แรก (หรือปิดหมด แสดงชื่อ + บรรทัดสรุป); Expression เป็น grid รูปย่อ 7 ช่อง แตะแล้วเปิด sheet ที่มีปุ่ม; hint ของ Scene แสดงครั้งเดียวบนสุด; เพิ่ม "ย้ายไปลำดับ…"
- ไฟล์: `components/story-editor/expressions.tsx:194-289`, `character-card.tsx`, `scene-card.tsx`, `folding-card.tsx`
- **แก้แล้ว (2026-11-13):** card ใน editor (Character, Bonds, Scene, Lore, Starting Beliefs, Saved replies, Replace rules) พับไว้ตั้งแต่แรก เปิดเมื่อแตะ เมื่อเพิ่งเพิ่ม หรือเมื่อกดลิงก์ไปช่องที่ต้องกรอก เครื่องจำ card ที่เปิดไว้ (`open:<key>`); Expressions เป็น grid รูปย่อ 7 ช่อง (มือถือแถวละ 4) แตะแล้วปุ่มของรูปนั้นขึ้นเต็มแถวใต้รูป วัดใหม่ที่ 390px: Characters 25,856 → 1,277px (เปิด Character 1 กับ Expression หนึ่งรูป: 4,685px), Scenes 21,995 → 2,564px, Lore 10,145 → 1,331px, Bonds 5,242 → 1,020px — hint ซ้ำของ Scene และ "ย้ายไปลำดับ…" ยังไม่ได้ทำ

## Low (15)

- **Home:** ป้าย "CONTINUE WHERE YOU LEFT OFF" ตัดให้ "OFF" อยู่บรรทัดเดียว (M7 รอบแรก) — ย่อเป็น "Continue"; ปุ่มม่วงทึบสองปุ่มแย่งกัน (New Story กับ Play) — ให้ New Story เป็นปุ่มเงียบ (`continue-row.tsx:21`, `app/page.tsx`)
- **Story Gallery:** ชื่อหน้า "Gallery · Welcome To Her Tribe" ขึ้นสองบรรทัด และหน้าตาต่างจาก Gallery รวม (`app/stories/[id]/gallery/page.tsx:43`); ป้าย "From an earlier version of this Chat" ทำให้แถวสูงขึ้น — เป็น badge บนรูปแทน (`gallery.tsx:268`)
- **Memory:** skeleton ตอนโหลดแทบมองไม่เห็นในธีมสว่าง
- **Dashboard:** มีแถบเมนูล่างโดยเลือก "Stories" อยู่ ทั้งที่แชตของมันซ่อนแถบนี้ ทางกลับมีแค่ลิงก์ "← Chat 2" เล็กๆ
- **Desktop:** แถว Continue ยืดถึง ~1,100px ปุ่ม Play อยู่สุดขวา; แชตกว้าง 720px เหลือที่ว่างข้างละ ~230px (ใช้วาง Memory/Dashboard ได้); editor กว้าง ~850px บรรทัด Setting ยาว ~110 ตัวอักษร — จำกัด ~44rem
- **Editor:** หัว card จัดไม่เหมือนกันในแต่ละแท็บ (chevron, ↑↓, Remove คนละที่) (`folding-card.tsx:58-65`, `starting-bonds-card.tsx:76`); ปุ่ม Assistant ใช้ไอคอน ✨ เดียวกับ Rewrite ของทุกช่อง (`editor-header.tsx:65`, L40 รอบแรก); รูป Reference ที่กำลังโหลดเป็นกล่องดำ 2:3 ไม่มี placeholder (`reference-image.tsx:22`); "Newest Snapshot" ขึ้นสองบรรทัด
- **People:** ช่อง Email ไม่มี hint, "Cap (USD)" ไม่บอกว่ารายเดือน, ปุ่ม Add ดูเหมือนปิดโดยไม่บอกเหตุผล (`people-card.tsx`)
- **สถานะ "Saved":** ขึ้นทั้งที่ยังไม่ได้แก้อะไร (หน้า Personas ว่าง, Settings) — แสดงหลังแก้ครั้งแรกเท่านั้น

## ยังไม่ได้ตรวจในรอบนี้

- **มือถือจริง:** notch/safe-area (H5 รอบแรก), แป้นพิมพ์บนจอ, PWA แบบติดตั้ง, Google sign-in บน iPhone
- **screen reader และคีย์บอร์ดล้วน** แบบเดินจริงทีละหน้า (axe ตรวจได้แค่โครงสร้าง)
- **มุมมองของ Member:** dev ปิด sign-in อยู่ ภาพทั้งหมดจึงเป็นมุมมอง Owner
- **การโต้ตอบที่เสียเงิน:** ส่งข้อความ, Snapshot, Read aloud — ไม่ได้กด
